AuraBot — Customer Support Agent on Bedrock AgentCore

A single support agent that answers order-status and product-FAQ questions. The order tool is a Lambda exposed as an MCP tool via an AgentCore Gateway; FAQs come from a Bedrock Knowledge Base (S3 Vectors); PII masking and denied topics are enforced by a Bedrock Guardrail.

Platform: Bedrock AgentCore Framework: Strands Model: Claude Haiku 4.5 Tool: Gateway → Lambda (MCP) Vectors: S3 Vectors Region: us-east-1

What it does

Order status

Calls get_order_status — a Lambda exposed as an MCP tool through the AgentCore Gateway.

Product FAQ

Calls search_faq — retrieves from a Bedrock Knowledge Base backed by S3 Vectors.

PII protection

Guardrail masks email, phone, name, address, card & SSN in-flight — still answers.

Denied topics

Guardrail refuses financial and medical advice, and off-scope questions.

Key design decisions

  • AgentCore, not Agents Classic — Classic is in maintenance mode and our sandbox couldn't create Classic agents; AgentCore is the platform we're transitioning to. Concepts map 1:1.
  • Gateway + Lambda (MCP tool) — the order tool is a real, auth-protected, reusable service. Gateway auto-handles OAuth (Cognito) and outbound IAM.
  • S3 Vectors, not OpenSearch Serverless — no idle floor vs a ~$700/month baseline; ~10–100x cheaper for a low-traffic FAQ.
  • Claude Haiku 4.5 — tool-routing + short replies, so Haiku is cheaper/faster; Sonnet 4.5 is a one-line fallback.
  • PII = Mask, not Block — masking strips the sensitive text but still answers; blocking would refuse any message containing an email.
